# HR-Analytics-Dashboard-Power-BI-
📊 HR Analytics Dashboard - Power BI

🚀 Overview
An interactive Power BI dashboard built to analyze employee workforce data, track attrition trends, and derive key HR insights.

🔑 Key Features
 KPI Tracking: Monitored total headcount, active employees, and attrition rates 📊.
 Attrition Insights: Analyzed employee turnover reasons and demographic breakdowns 📉.
 Department Metrics: Evaluated performance and salary distributions across departments 💰.
 Interactive Slicers: Added dynamic filters for deep-dive exploratory analysis 🔍.
 
🛠️ Tech Stack
 Tool: Microsoft Power BI
 Skills: DAX Measures, Data Modeling, Power Query
